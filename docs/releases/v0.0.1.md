# Restrict Language v0.0.1

Restrict Language v0.0.1 is the first public release of the language, compiler,
and project toolchain.

Restrict puts values before the operations that consume them. Its OSV calling
order makes data flow read left to right, while affine checks make ownership
and accidental reuse visible at compile time. The compiler turns that model
into WebAssembly without a tracing garbage collector.

## Language highlights

- OSV-only calls: `value |> function`, `(args) function`, and `() function`
- typed context scopes with composable `with Context { bindings } { body }` expressions
- affine `val` bindings and explicit `mut val` bindings
- bidirectional type inference for generics, lambdas, branches, and containers
- records, prototype-style `clone` and `freeze`, and record patterns
- closed user-defined enums with qualified OSV constructors and exhaustive matches
- built-in `Option<T>` and `Result<T, E>` with qualified value construction
- static method-only forms, concrete record `takes`, and generic `of` bounds
- compiler-provided and user-adopted `Display` behavior for `display`, `print`, and `println`
- source modules, dotted imports, and deterministic direct local dependencies

## Compiler and tools

- WebAssembly text and binary generation with arena-backed internal values
- a checked compiler handoff that preserves inferred expression and ABI facts
- the Warder project tool for project creation, checking, building, running, testing, and diagnostics
- a language server over stdio
- a browser playground with local compilation, execution, tokens, AST, Wasm, and diagnostics
- release gates that compile public examples and execute the checked-in browser runtime

## Deliberate boundaries

The language can use records, strings, collections, sum types, lambdas, forms,
and generics internally. The default host-visible WebAssembly ABI remains
limited to concrete scalar parameters and results. The flat record ABI is
experimental and opt-in; temporal affine types, WIT and the Component Model,
dynamic form dispatch, generic or recursive enums, postfix `?`, and a public
package registry remain future work.
