The idea

Make data flow read in the direction it moves.

Restrict puts objects and arguments before verbs. Pipes are not an alternate style layered onto conventional calls; they are part of one consistent calling model. 

val answer = 41
    |> increment

A deliberate first release

v0.0.1 is the line we move forward from.

The first release includes closed enums, qualified OSV constructors, and a narrow, statically dispatched form/takes system. Generic and composite values work inside Restrict programs, while the default host boundary stays deliberately scalar until its record, collection, and generic ABI is designed.
