The idea

Make data flow read in the direction it moves.

Restrict puts objects and arguments before verbs. Pipes are not an alternate style layered onto conventional calls; they are part of one consistent calling model. 

val answer = 41
    |> increment
    |> double

An honest preview

v0.0.1 draws a line around what is ready.

Generic and composite values work inside Restrict programs. The host boundary stays deliberately scalar while record, string, list, and generic ABI design remains open. Temporal affine types, user-defined ADTs, and source-level forms are reserved for later work.
